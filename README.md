
# My Favorite Movie: Inside Out 2 🎬

## Introduction

My favorite movie is **Inside Out 2**. It is an *animated movie* about a girl named Riley who experiences different emotions as she grows older.

I like this movie because it teaches us about **friendship, emotions, and accepting ourselves**.
